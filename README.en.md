# Codex++ List Pagebuster

A third-party user script for [Codex++](https://github.com/b-nnett/codex-plusplus). It attempts to surface more local Codex Desktop history entries in the native sidebar, and adds an `Extra history` fallback section for sessions that Codex Desktop does not include in its native recent list.

This is not an official OpenAI Codex feature and is not bundled with Codex++. It relies on Codex Desktop internal frontend APIs and may break after app updates.

See [README.md](README.md) for the full Chinese documentation.
